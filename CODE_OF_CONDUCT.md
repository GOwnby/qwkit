# Code of Conduct

This project follows the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, welcome newcomers, and focus criticism on
ideas and code rather than people. Harassment or discriminatory behaviour is not tolerated.

Report unacceptable behaviour privately to the maintainer, Gracen Ownby (University of Oklahoma).
Reports will be handled confidentially.
